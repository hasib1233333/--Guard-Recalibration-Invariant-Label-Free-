Title:
T-Guard: Recalibration-Invariant, Label-Free Drift Detection via Cross-Signal Rank-Agreement Decay 
Abstract:
Deployed classifiers are routinely monitored for silent degradation using only their own outputs, since ground-truth labels are typically unavailable at deployment time. Existing label-free monitors—confidence-distribution tests, population-stability indices, and related methods—implicitly assume the model's confidence values are stably calibrated; when a model is merely recalibrated (e.g., via temperature or Platt scaling, routine in MLOps pipelines) with no change to the underlying data, these monitors mistake recalibration for genuine drift. We introduce $\tau$-Guard, a label-free signal that instead monitors the rank agreement (Kendall's $\tau$) between a model's predictive-entropy score and an independent feature-space novelty score, which is provably invariant to any strictly monotone recalibration of confidence. We give an exact invariance lemma, a bootstrap-calibrated test with controlled false-positive rate, and an extensive empirical evaluation: eight datasets spanning medical, signal-processing, image, and synthetic domains; three classifier families (logistic regression, random forest, SVM); six label-free methods, including two additional baselines (STUDD, D3) reimplemented for this study; a genuine ablation over window size, bootstrap size, novelty-score choice, and rank-statistic choice; a sensitivity analysis over significance level, temperature, and calibration-set size; a runtime/memory/storage complexity comparison; and a real-world case study on the Electricity concept-drift benchmark. Pooled over 6,750 trials across the full dataset battery, two standard baselines (Confidence-KS, PSI) go from a well-calibrated $\approx5\text{--}10\%$ false-positive rate to $\approx80\text{--}99\%$ under pure recalibration (McNemar $p < 10^{-300}$), while $\tau$-Guard's rate is statistically unchanged, and this holds across all three classifier families. Under genuine shift with simultaneous recalibration, $\tau$-Guard's detection signal is preserved or strengthened on most datasets, while the confidence-distribution baselines' alerts become uninformative once saturated. We report every limitation as directly as every strength: an approximate (not exact) invariance guarantee under multiclass temperature scaling, a discriminative-classifier baseline (D3) with better raw sensitivity but an order of magnitude higher runtime cost, a student-teacher baseline (STUDD) that is cheap but weak at detecting the shifts we study, honest dataset-dependent sensitivity limits, and the structural blind spot to pure concept drift shared by every label-free monitor in this comparison. 
Keywords:Recalibration-Invariant, Label-Free Drift Detection, Cross-Signal Rank-Agreement Decay, Concept Drift, Model Monitoring, Kendall's Tau, Predictive Entropy, Mahalanobis Distance, Machine Learning Operations (MLOps)
